# 批条 · 远程脚本仓库

角色卡《批条》（权蛆杯参赛作品）的手机面板与私信生成器远程托管仓库。
卡内只带加载器：版本指针（tag 固定起步）→ jsDelivr 三域备胎 → 12s 超时闸刀 → eval。

## 目录

- `dist/phone_panel.js` — 悬浮手机面板（微信/联系人/关系网/备忘录四应用）
- `dist/dm_generator.js` — 微信私信生成器（generateRaw + json_schema，phone 子树唯一写入者）

## 版本

- 使用时在卡内加载器 `REF` 常量固定 tag（如 `v0.2.0`）；热更新走 tag 递进或后续接入指针服务
- 指针键值只允许干净字符（`[\w.\-]`），防路径注入
